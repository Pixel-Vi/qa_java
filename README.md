# 🐾 Исследование семейства кошачьих (Felidae)

Java-проект, моделирующий таксономию семейства кошачьих и его связь с хищниками.  
Проект создан для практики написания unit-тестов в Java (JUnit 4 + Mockito).

## 📖 Описание

Проект реализует упрощённую систему классификации животных с акцентом на семейство кошачьих (Felidae):

- **Animal** — базовый класс для всех животных (определение типа питания, семейства)
- **Predator** — интерфейс хищника (метод `eatMeat()`)
- **Feline** — представитель семейства кошачьих, расширяет `Animal` и реализует `Predator`
- **Cat** — домашняя кошка (использует композицию через `Predator`)
- **Lion** — специализированный представитель кошачьих (лев, с логикой определения гривы)

## 🏗️ Архитектура

```
Animal (базовый класс)
  └── Feline extends Animal implements Predator
        └── Lion extends Feline

Cat (отдельный класс, использует композицию Predator)
```

## 🚀 Быстрый старт

### Требования

- JDK 11+
- Maven 3.6+

### Сборка проекта

```bash
mvn clean compile
```

### Запуск тестов

```bash
mvn test
```

### Отчёт о покрытии кода

```bash
mvn test jacoco:report
```

Отчёт доступен в `target/site/jacoco/index.html`.

## 🧪 Тесты

Проект демонстрирует различные подходы к тестированию:

- **Базовые ассерты** (`assertEquals`, `assertTrue`, `assertFalse`)
- **Методы перед тестом** (`@Before`)
- **Mockito** (`@Mock`, `@RunWith(MockitoJUnitRunner.class)`)
- **Параметризованные тесты** (`@RunWith(Parameterized.class)`)

## 📝 Примечания

- Все строковые значения, сообщения об ошибках и ассерты написаны на русском языке.
- Проект не имеет точки входа (`main`-метод) — это библиотека + набор тестов.
- JaCoCo настроен автоматически: отчёт генерируется при запуске `mvn test`.
